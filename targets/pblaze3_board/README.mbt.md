# PBlaze3 physical target generation

This package owns deterministic physical build inputs and the provisional
2GiB board contract. It does not change portable Qwen arithmetic or claim
physical qualification. See `boards/pblaze3/README.md` for provenance,
clock/reset policy, build commands and the board-arrival gate.

The opt-in `ddr-status-ila`, `ddr-mig-ila`, `ddr-xdma-ila` and
`accelerator-core-ila` profiles each instantiate one ordinary native ILA
for Vivado 2026.1 BASIC. Their raw-oscillator hub clock is independent of
the DDR/PCIe clocks; each AXI capture still needs its own clock running.
The combined `ddr-smoke-ila` and `accelerator-ila` profiles retain their
original layouts, but actual linked synthesis rejects multiple ILA instances
under the installed BASIC license (Chipscope16-620). See
[the diagnostic image guide](../../docs/PBLAZE3_ILA.md) for probe layouts,
clock prerequisites, accepted image identities and the separate hardware
capture gate. Production modes retain their original generated bytes.

```mbt check
///|
test "user-selected capacity is the accelerator default profile" {
  let mode = @pblaze3_board.parse_mode("accelerator")
  assert_eq(mode.memory_bytes(), 2147483648UL)
  assert_eq(mode.vivado_release(), "2025.2")
}
```
