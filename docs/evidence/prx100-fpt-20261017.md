# PRX100 BF16/FP32 JTAG host transfers — 2026-10-17

The selected host path uses **30 MHz JTAG**, reusable Vivado transactions and
one burst for the three adjacent configuration words. The existing FPDDR1.3
bitstream remains unchanged. In three interleaved matched campaigns per profile,
median complete 48-job host time falls from **77.948 to 25.423 ms**, a **3.066×
improvement**. The identical 22 KiB payload uploads in **96.768 ms**, versus
**367.261 ms** at baseline. All **318 projections / 2,544 FP32 outputs per
profile** match the independent CPU reference bit for bit.

The integer core, all FP hardware and existing profiles remain unchanged.
All **352** protected production/interface identities and all sixteen re-exported
hardware files match their pre-task inputs. This is a host-transfer improvement;
FP arithmetic remains 4,100 cycles / 82 µs at K1024.

## Scope and implementation

The [host-transfer contract](../PRX100_JTAG_HOST_TRANSFERS.md) describes
`scripts/prx100-fpt-{board,metrics,probe,close}.mbtx`. The original
`prx100-fpo-audit.mbtx` remains the independent raw-memory CPU auditor.
No hardware construction, core, controller, bridge, DDR layout, ABI or clock
constraint changes are required. The same MoonBit-generated canonical IR and
SystemVerilog, previously qualified through Vivado, produce the programmed bitstream.

CPU_TAG ME10E06D1010A reports supported rates including 30 MHz. The driver sets
the rate before target opening and requires its readback to match. Reusable
transactions are keyed by operation, address and burst length; every repeated
write updates DATA. Length/job/vector configuration uses one ordered INCR burst.
The baseline creates/deletes each object and writes configuration separately.
Both paths execute and check every AXI response individually. Burst bounds,
full input readbacks, guards, all 34 diagnostic words and fault checks remain.

K1024, normalized embedding activations for token IDs 42, 100 and 1000.

## Matched end-to-end measurements

All runs use the same PRX100-D, xc7a100tfgg676-2, Linux guest, bitstream,
50 MHz core, 100 MHz DDR UI and pinned Vivado 2025.2 build 6299465. No CAD jobs
run during measurement. The selected order is baseline-b1, fast-b1, fast-b2,
baseline-b2, baseline-b3, fast-b3; each run reprograms the same volatile bitstream.
Each campaign has 16 batches / 106 projections / 848 outputs: 91 full K1024
projections and 15 prefixes at K1,2,3,16,1023. Per profile this totals 273 full
projections and 45 prefixes. Earlier rate probes and preliminary campaigns are
retained separately and excluded from the selected statistics.

The complete batch timer starts before configuration/cache checks and ends
after START, polling, every output, all counters, final error read and local
checks. It excludes programming, Vivado startup, precomputed CPU references and
output-table logging after verification. This is broader than the historical
`results.tsv` timers. Campaign wall time includes all input uploads, two complete
input readbacks, guard checks and all 106 projections.

Diagnostic payload is equal between profiles, unlike the preceding FPDDR1.2/1.3
hardware comparison.

## Qualification and rejected candidate

- All six selected raw-memory CPU audits pass on Linux and Mac, and each pair's
  JSON is byte-identical. Independent phase-accounting JSON also matches byte
  for byte. Every input word and24 boundary guard words is read before and after
  execution; all output words, overlap counters, cache states and final drain
  diagnostics pass. Repeated lengths/configurations exercise updated cached DATA.
- The independent CPU audit rejects a consistent one-bit corruption in the
  result table's expected/actual fields and matching raw DDR result read, while
  operand writes remain unchanged. The timing checker rejects a one-microsecond
  inconsistency in a batch total. Neither negative control emits a PASS receipt.
- `moon info`, `moon fmt`, native deny-warning check and all **1,225 native
  tests** pass. Final hardware re-export matches all sixteen physical inputs.
  Existing public interfaces and352 protected identities are unchanged.
- RTL differential, synthesis, formal and physical timing qualification is
  inherited by exact source/bit identity from
  [FPDDR1.3](prx100-fpo-20261017.md), archive seal
  `ffc26ff158208b6c410f47ad61da8d8fefb01b0072a65371b51db49492de9d8c`.
  No new CAD or formal run is claimed. The existing routed setup/hold margins
  remain+0.958/+0.048 ns, with all12 bus-skew checks passing.
- A retained16-write queued-upload experiment fails with Xicom50-38: the
  existing vendor JTAG_AXI XCI has `RD_TXN_QUEUE_LENGTH=1` and
  `WR_TXN_QUEUE_LENGTH=1`. Although Vivado supports larger queues, this target
  cannot accept that group. The published driver retains individually checked
  accesses; no queued-transfer improvement is claimed. Its rejected root,
  source, logs and experimental auditor are retained, and its owned server is
  closed. A larger hardware queue would require separate target qualification.
