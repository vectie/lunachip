The prior routed critical path was the ordered FP32 accumulator: 24.721 ns through 41 logic levels. The MoonBit implementation now uses exponent-only alignment selection, parallel close subtraction directions and the normalization tree's already shifted value. This removes serial logic from the feedback path and permits the qualified 41.667 MHz target clock. Sixteen lanes still accept one separately rounded product per edge, in the original K order. BF16/FP32 precision, rounding, gradual underflow, signed zero, infinities and canonical NaNs are preserved. Only feedback.mbt changed among 1,448 module inputs; all 199 protected integer inputs and public interfaces are unchanged.
