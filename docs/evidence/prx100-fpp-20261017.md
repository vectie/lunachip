## Architecture and arithmetic

LunaWire elaborates `designs/floating_point/parallel.mbt` and `pipeline.mbt`
into canonical IR; LunaWave simulates it; the SystemVerilog backend emits RTL
for Vivado. Eight1024×32 BRAM banks each hold packed BF16 activation/weight
operands. Each lane has a three-stage multiplier and five-stage accumulator.
The next input is issued every five cycles, with four drain cycles per job:
`5*K+4` active edges.

Each output preserves increasing-k accumulation and separate FP32-rounded
multiply/add operations. There is no reassociation or fused multiply-add.
RNE, gradual underflow, signed zeros, infinities and canonical quiet NaN
`7fc00000` retain the scalar contract. Exception flags and NaN payload
preservation remain outside the interface. No vendor floating-point IP or
host integer dequantization computes the hardware results.

The fixture is unchanged: `Qwen/Qwen3-0.6B@c1899de289a04d12100db370d81485cdf75e47ca`,
layer0 q_proj channels0..7, K1024, normalized embeddings for token IDs42/100/1000.
