## Changed target contract

Target register version is `00010006`. The sequencer collects four adjacent C words and sums them using the existing INT32 rules, then requests one aligned16-byte write. Partial results retain offset `tile*32+channel*4`; eight final sums retain their32-byte layout. A successful partial batch ACK advances the acknowledged-word count by four. DONE follows the second final-sum ACK.

The bridge latches all four words at acceptance and serializes one header/data0 plus three data flits through its existing64-bit request FIFO. The100MHz side gathers all words before one full128-bit native write, mask0. Command/WDF acceptance remain independent. Rejected line addresses drain the flits without native issue; the word portal retains its four-byte mask and single ACK. See [the contract](../PRX100_DDR_RESULT_WRITES.md).
