# PRX100 portable word-memory optimization — 2026-10-17

The opt-in portable word-read core is implemented, programmed through CPU_TAG,
and verified on the PRX100-D. A fresh physical A/B reduced median FPGA latency
**1.12710→0.53526 ms: 52.51% lower, 2.11× faster**. All 20 jobs on each image
matched the independent CPU reference. This task explicitly changes the core
transport; the legacy byte-read generator retains its exact canonical IR,
ordinary SystemVerilog and name manifest.

## Transport and correctness

The [portable contract](../PHASE6_WORD_MEMORY.md) adds
`ring_concurrent_word_tile`. Each descriptor uses eight aligned word reads
instead of 32 byte reads. Operand loaders use a word when four bytes fit in
the current row at an aligned address, with byte fallback elsewhere. A held
word is unpacked through the existing signed-byte bank channel, preserving
backpressure, prefix progress, poison and reset. Stores remain four-byte
writes. Target staging checks bounds before BRAM enable and holds tagged
words or zero-extended selected bytes until accepted.

Core requests fall **280→76 per tile, 72.86% fewer**. New physical counters
verify 4352 reads, all words, zero byte reads and 512 writes per full 64-tile
projection: 4864 accepted transactions. The legacy 17920 count derives from
the retained exact-core replay; its physical image lacks the new counters.
The DDR schedule remains 2304 logical reads, 520 logical writes, 788 descriptor
words, 512 partial words and 256 completions per full projection.

Across both images, **40 jobs, 3120 selected partials and 320 final sums**
match the CPU calculation. Independent auditors check **24864 raw accesses**,
read back and postcheck each image's 11264 input bytes, 12 guards and both DDR
endpoints. Guest and Mac audit JSONs are byte identical for each image. An
offline corrupted partial, consistently propagated through raw logs and
transaction records, is rejected against the CPU reference. Quantization
errors versus FP64 remain unchanged: maximum absolute errors 0.002814489,
0.004246594 and 0.004989698 for the three vectors.

## Validation and routing

`moon info`, `moon fmt`, native warning-strict check and **1176 native tests**
pass. Tests cover all alignments, row tails, odd strides, signed edges, held
bank writes, word faults, prefix progress, poison and reset. Legacy IR/SV/name
identity tests pass. The source guard verifies 201 untouched identities and
the explicitly scoped core edits. All 18 physical inputs match deterministic
re-export byte for byte. Pinned Verilator 5.050 checks all outputs for **3947
cycles each** of the new core and controller replay; pinned Yosys 0.68
synthesizes both. Core replay records 544 word reads and 64 writes over two
four-tile jobs.

Selected formal tasks pass: exact production loader functions at BMC bound
32, seven cover witnesses, and controller BMC bound 32. Deliberate loader
capture and controller memory-gate mutations fail at step 4 as expected.
These use explicit free interface cuts and target binary encoding normalization;
they are bounded local evidence. The controller prefix does not reach its
36-word prefill completion. A startup exit 139 and three induction timeouts
(300 seconds each, bounded bases passing) remain retained. **No unbounded
theorem for the new loader, core, queue or whole device is claimed.** Earlier
legacy core proofs do not qualify the new variant.
