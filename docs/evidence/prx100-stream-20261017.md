## Target-only changes

Target version `00010007` uses one128-byte weight stream instead of eight separately owned16-byte reads. The fast side has one outstanding native read and four response registers; FIFO credits gate drainage before the next line is issued. The slow side owns all32 beats and checks last at31. Invalid alignment, calibration loss, malformed native returns and partial-stream reset fail closed. Burst reads do not install the word portal cache. Existing word and line operations retain their behavior.

Descriptor patching starts after the reader releases the ring image and occupies gaps between incoming operand words. DDR words have priority on the single staging write port. The descriptor index advances only on actual writes; publication requires all operands and all patch words. Result collection reads C[n+1] while capturing C[n], removing six redundant wait edges per tile. See [the design contract](../PRX100_DDR_STREAMING.md).
