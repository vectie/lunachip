# Fetched Store packed retrieval and witness validation

## Purpose

Obtain a complete execution witness for the original fetched Store cover, not
just a SAT answer. SAT establishes existence under the declared premises; the
certificate provides the machine states needed to check the original equations
and explain descriptor admission, Load, MatMul, result capture, Store data and
ordered retirement. This is a reachability and integration check, not universal
device safety or eventual completion for every schedule.

Packing changes only how those states are requested after search: one balanced
concatenation contains all840 original9716-bit states and the original cover
bit. It introduces no initialization, memory value or address assumption.
Unknown memory must remain free, because forcing it to zero could hide a read
before write. Full-width addresses, guards and collision behavior must remain
exact, because truncating them could hide an illegal or aliased access.
