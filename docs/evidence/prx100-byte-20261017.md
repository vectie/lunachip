## Change and remaining limit

The [target contract](../PRX100_BYTE_MEMORY.md) adds a second synchronous
ReadOld/HoldLast port to the4KiB staging memory. Target-side result collection
can read without changing a held tagged core byte or pausing new acceptance.
C[0] is read in the retirement join; C[channel+1] is read during the current
partial's DDR request/ACK. State10 latches the preceding edge's value. State9's
separate read-issue step is removed. The single write-port exclusion, two C
banks, descriptor leases, result ordering and error handling are retained.
The target register version is0x00010003; Device ABI1.0/descriptor0.2 are unchanged.

The unchanged core captures a client, offers its request, then waits for its
response. The previous adapter already supplied a synchronous byte at the
earliest consumable edge. A tile still performs128 descriptor-byte reads,
144 operand-byte reads and8 result-word writes. Minimum three-edge spacing
accounts for roughly1.075ms across64 tiles at50MHz, before other overhead.
This is a source-derived scheduling limit, not a named formal throughput proof.
The serialized portable protocol remains the dominant cost.
