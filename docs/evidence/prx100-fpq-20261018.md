# PRX100 JTAG AXI queues and BF16/FP32 projection — 2026-10-18

FPDDR1.3Q is programmed on the PRX100-D with **16 read and16 write JTAG AXI
queue entries** and batched DDR transfers at30 MHz. Median application wall
time for the same input upload, readbacks and106 Qwen projections falls from
**637.402 to485.841 ms**, a **1.312× improvement /23.778% less time**. The22 KiB
upload improves **2.345×**, from117.365 to50.048 ms. All three matched profiles
pass **318 projections /2,544 CPU-exact FP32 outputs each**.

The integer core, FP arithmetic, controller, bridge and all first-party RTL
remain unchanged: **352 protected production/interface identities** and all
**16 canonical/export files** match before and after the task. Only vendor
JTAG AXI read/write queue-length user parameters change, from1 to16. A fresh
Vivado synthesis/place/route and physical qualification covers that target change.

## Target and data validation

The [queue contract](../PRX100_JTAG_AXI_QUEUES.md) defines the reproducible
`scripts/prx100-fpq-{build,route,review,board,audit,groups,metrics,close}.mbtx`
entry points. MoonBit still generates the same canonical IR/SystemVerilog;
pinned Vivado changes the vendor shell implementation. MMIO remains0x46504433 /
version0x10003; DDR layout,50 MHz core and100 MHz DDR UI remain unchanged.
Full arithmetic remains4,100 cycles /82 µs.

Groups contain at most16 same-direction transactions, each at most256 words
without crossing4 KiB. Transactions are reused and write DATA updates before
each run. Queueing covers weight/activation uploads/readbacks and the two-burst
384-word result read for48 jobs. Control/configuration, polling, errors, short
transfers and34 diagnostic/result words remain serial. No read/write dependency
is placed within one group. Refreshed hardware properties report both queue
lengths16 for every new-bit run and1 for every old-bit baseline; independent
runtime-depth checks pass for all nine selected runs.

Vivado exposes final group RRESP/BRESP. `GROUP_OKAY` records that observation,
rather than claiming individual responses. Every DATA word is retained and
checked. Independent group audits bind raw/result hashes and verify coverage,
capacity, addresses, lengths, boundary rules and timing. Each queued campaign
executes **112 transactions in11 groups**: four write groups /11,264 words and
seven read groups /17,280 words. Remaining accesses check individual responses.

Before timing the real upload, both profiles write and verify the complement
of every model input. Each actual model word must replace its verified poison
value before START. Audits require two writes and three readbacks per input:
poison, actual model before jobs, actual model after jobs. All24 boundary guard
words are read before/after execution. Stale DDR therefore cannot hide a lost
model write. Seven invalid bulk ranges/operations are rejected before creating
transactions; five invalid device accesses return their expected SLVERR.

## Qualification

- All nine selected CPU/group/timing audits pass independently on Linux and
  Mac; all27 JSON pairs are byte-identical. CPU results are reconstructed from
  raw DDR operand writes, rather than trusting result-table expectations.
- Four negatives reject a corrupt poison read, a consistent table/raw-result
  bit flip, an oversized17-entry group, and a one-microsecond inconsistent phase
  total. No negative emits a PASS receipt.
- `moon info`, `moon fmt`, native deny-warning check and all **1,225 native
  tests** pass. Sixteen export files and352 protected identities/public interfaces
  remain exact. Named controller/core RTL differential, Yosys and scoped formal
  evidence is inherited by exact identity from [FPDDR1.3](prx100-fpo-20261017.md);
  these gates were not rerun for unchanged first-party RTL. No unbounded vendor
  queue/fault-completion proof or individual queued-response proof is claimed.
- Pinned Vivado2025.2 build6299465, qualified MIG, JTAG AXI1.2 revision23. All
  user component parameters compare exactly except the two queue lengths. Routea1
  meets setup+0.958 ns but fails six hold endpoints, worst−0.113 ns. Hold repaira2
  closes **setup+0.958 ns /hold+0.048 ns**, zero failing endpoints. Both attempts
  are retained with unchanged RTL, clocks and exceptions. No failed candidate
  was programmed.
- All **2,999 core FD clock pins** use20 ns `clk50`. All12 unfiltered bus-skew
  constraints pass, minimum slack **18.854 ns**. DRC has no errors or critical
  warnings. Existing vendor CDC/reset advisories remain; these are digital
  timing checks, not analog CDC/MTBF evidence.
- Whole target: **19,335 LUT,11,846 FF,26.5 BRAM36 equivalents,0 DSP**, versus
 16,099 LUT,11,720 FF,23 BRAM36 equivalents previously. Queues add3,236 LUT,
