## Local engine and queue composition

Use the actual 8×8 queue roles to check next-PRE transitions:

- FIFO pop, capture, reserve and head finish advance the actual head controller.
- Each loader/compute/Store Done state returns to Idle at the next PRE because
  the queue wires its completion-ready high outside reset.
- An actual matching entry collector sets that entry terminal at the next
  PRE unless the same edge allocates a new entry, whose documented allocation
  priority must remain intact.

These are local progress lemmas. They do not yet prove that every Done engine
has a live matching retirement owner, the six-predecessor rank, cursor/capture
progress or dependency drainage. Those links must compose before crediting
L1666/S898/M99 and the final11718 deadline.
